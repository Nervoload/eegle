# EEGle example model plugins

This is a separate distribution, not a hidden model runtime inside EEGle. It
implements two genuinely different algorithms—valid-sample mean and absolute
peak—and publishes ordinary `eegle.plugins` descriptors. All three models
return the explicit `all_samples_invalid` abstention when no finite valid sample
is available; they never reduce an empty array or emit a non-finite score.

```bash
python -m pip install .
eegle plugin inspect eegle.example_models.mean_threshold
eegle plugin check eegle.example_models.mean_threshold
```

The corresponding artifact-free manifests are generated by
`eegle.authoring.reference_model_manifests()`. A real model plugin should
usually package content-addressed artifacts, verify them through
`ModelConstructionContext`, return `ModelResult`, and keep labels/outcomes out
of inference metadata. See `docs/PLUGIN_DEVELOPMENT.md`.
