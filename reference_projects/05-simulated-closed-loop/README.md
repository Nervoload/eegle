# Simulated closed-loop action

Declares a structured feedback request and simulated actuator. The portable
suite cannot authorize itself: absent an independent deployment provider and
grant, compilation remains observe-only.

```bash
python -m pip install ../../examples/plugins/eegle-example-models
eegle compile .
eegle explain .
eegle rehearse .
eegle inspect .
eegle replay .
```
