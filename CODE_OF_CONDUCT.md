# Code of Conduct

EEGle contributors are expected to be respectful, precise, and safety-minded.
This project includes experimental neuroscience tooling, so discussions should
prioritize reproducibility, careful claims, and constructive review.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, or pressuring maintainers or contributors to make unsupported
scientific or clinical claims.

Report concerns privately to the project maintainer. Maintainers may remove
content, moderate discussions, or block participants when needed to keep the
project healthy.
